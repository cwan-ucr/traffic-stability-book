# Traffic Stability and Control

Public research-library repository for Changxin Wan's book, interactive lab,
experiments, and reproducible code.

## Repository Structure

- `book/`: online chapters and book releases
- `lab/`: interactive traffic-stability experiments
- `experiments/`: numerical cases and processed result data
- `code/`: source packages and reproduction instructions
- `assets/`: cover, figures, and shared site assets

The first commit intentionally contains the publishing shell only. Book PDFs,
lab code, experiment data, and research archives should be added when their
source files are ready rather than represented by placeholder downloads.

## Local Preview

Open `index.html` directly or serve this directory with a local static server.
