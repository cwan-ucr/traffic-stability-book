# Book release

This directory contains the public 2026 teaching and research edition of
*跟驰模型与宏观交通流模型的稳定性*.

- `traffic-stability-book.pdf`: the 224-page PDF release.
- `source/stability-enhanced.tex`: the LaTeX manuscript source.
- `source/assets/`: figures required by the manuscript source.

The manuscript text, typography, and original figures are not covered by the
MIT license in `../code/`.
