# Experiments

This directory is the public index for the reproducible cases linked to the
book and browser lab.

- `manifest.json`: shared M01-M06 and D01 experiment metadata.
- `metrics/`: machine-readable reference outputs used in the manuscript.
- `index.html`: human-readable case index for GitHub Pages.

Executable scripts, derived data, generated figures, and tests are in
`../code/`. Raw NGSIM input data is intentionally excluded; see
`../code/data/README.md` for its documented source and retrieval workflow.
