Numerical cases and data

The first public set contains six numerical stability cases and one empirical NGSIM trajectory analysis. The shared machine-readable manifest and reference metrics are available below.

    Linear second-order follower; analytical solution checked point-by-point against RK4 integration.

  2. M02
    有限环道与离散波长

    Linearized IDM ring experiment showing finite-domain wavelength effects.

  3. M03
    原始 IDM 稳定与失稳

    Nonlinear IDM ring integration under stable and unstable equilibrium speeds.

  4. M04
    前车加速度反馈

    Gradually activates cyclic acceleration feed-forward during a running simulation.

  5. M05
    时间步长收敛检查

    Growth-rate convergence study using three time steps.

  6. M06
    IDM 基本图下的 LWR 激波

    LWR finite-volume experiment with IDM equilibrium flow.

  7. D01
    NGSIM US-101 自然扰动传播

    Empirical trajectory analysis of a three-minute natural disturbance segment.
